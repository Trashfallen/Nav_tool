# Nav Tool

[English version](README.md)

Настольная программа для тех, кто ведет документацию на MkDocs (подход «документация как код»). Все, что обычно делается руками в `mkdocs.yml`, редакторе и git, собрано в одном окне.

## Возможности

- **Меню сайта (`nav`).** Дерево разделов и страниц, добавление страниц галочками, новые разделы (в том числе вложенные пустые), переименование, порядок, удаление вместе с файлами. `mkdocs.yml` правится построчно, комментарии и форматирование сохраняются.
- **Файлы `docs/`.** Дерево всех файлов, новые файлы и папки, перенос перетаскиванием с автоматической правкой путей в меню и относительных ссылок.
- **Редактор Markdown.** Панель форматирования, предпросмотр тем же движком и расширениями, что у mkdocs (видно «кашу» до коммита), диаграммы Mermaid, картинки из файла или буфера обмена (кладутся рядом со страницей), синхронная прокрутка, масштаб.
- **Шаблоны.** Свои заготовки страниц и блоков с подстановкой номера задачи, заголовка и даты. Передаются коллегам одним файлом.
- **Проверка `mkdocs.yml`.** Показывает ошибку с номером строки, простые ошибки исправляет кнопкой, не дает записать правку, которая сломает файл.
- **Локальный сайт.** `mkdocs serve` одной кнопкой. Сам ставит mkdocs и плагины из `requirements.txt` проекта в свое окружение, умеет поставить Node.js и likec4 для C4-диаграмм.
- **Git.** Изменения, отмена по файлу, ветки (выбор, создание, переключение с откладыванием правок), коммит выбранных файлов, push, ссылка на Merge Request, скачивание обновлений, добавление в свою ветку другой неслитой ветки с объединением пунктов меню при конфликте. У страниц видно, из какой ветки они пришли.
- **Отмена.** Почти любое действие откатывается кнопкой «Отменить».
- **Светлая и темная тема.**

## Как устроено

- `nav_tool.py` поднимает локальный HTTP-сервер на `127.0.0.1` и открывает интерфейс (`ui.html`) в окне Edge или Chrome в режиме приложения со своим профилем.
- Данные уходят только на твой git-сервер и в источник обновлений. Mermaid для предпросмотра грузится с jsDelivr.
- mkdocs и плагины работают в отдельном виртуальном окружении `.mkdocs-env` рядом с программой, системный Python не засоряется.
- Обновления приходят из этого репозитория: когда выходит новая версия, кнопка «Обновить программу» показывает список изменений, скачивает новую версию и перезапускает программу. Настройки, шаблоны и копии для отката лежат в папке программы и в git не попадают.

## Технологии

- **Python 3.10+**, бэкенд на стандартном `http.server`.
- [PyYAML](https://pyyaml.org) и [Python-Markdown](https://python-markdown.github.io) - `mkdocs.yml` и предпросмотр.
- Интерфейс - одна страница на **HTML/JS**, [Mermaid](https://mermaid.js.org) для диаграмм.
- **Git** из командной строки для всех действий с репозиторием.

## Что нужно

- Windows 10 или 11.
- Python 3.10 или новее (при установке отметить «Add python.exe to PATH»).
- Git.
- Microsoft Edge или Google Chrome (в Windows Edge есть всегда).
- Node.js нужен только для C4-диаграмм likec4 на локальном сайте, программа может поставить его сама.

Пакеты Python руками ставить не нужно.

## Установка

```
git clone https://github.com/Trashfallen/Nav_tool.git NavTool
```

Один раз запустить `NavTool\run.bat`. Программа создаст на рабочем столе ярлык «Nav Tool», дальше запускать им.

## Шаблоны

В репозитории шаблонов нет: у каждой команды они свои. Шаблоны передаются файлом `navtool-templates.json`: в редакторе «Шаблоны» -> «Загрузить шаблоны из файла», «Сохранить шаблоны в файл» выгружает свои. В тексте шаблона можно использовать метки `{{LES}}`, `{{TITLE}}`, `{{NAME}}`, `{{DATE}}`.
